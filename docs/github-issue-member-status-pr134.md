## 멤버 설정 화면

### 현재 멤버 (ACTIVE)
- 기존과 같이 **나** / **멤버 · N** 섹션에 표시됩니다.
- 온라인·오프라인 접속 배지, 방장의 위임·추방 메뉴는 **현재 참여 중인 멤버**에게만 노출됩니다.
- 방 나가기·방장 위임 필요 여부 판단도 **현재 멤버 수**만 기준으로 합니다. (나간 멤버는 카운트에 포함하지 않음)

### 이전 멤버 (LEFT)
- 방을 나갔거나 추방된 멤버는 **「이전 멤버 · N」** 섹션으로 분리해 표시합니다.
- 서버가 내려주는 목록 순서(현재 멤버 → 이전 멤버)를 그대로 따릅니다.
- 이전 멤버 카드에는 **「방 나감」** 보조 뱃지가 붙고, 접속 상태(온라인/오프라인) 배지는 보이지 않습니다.
- 카드는 읽기 전용 톤으로 표시되며, 방장도 위임·추방 버튼이 나오지 않습니다.

## 실시간 동작 (화면에서 체감되는 부분)

- 다른 사람이 **방 나가기**를 해도, 새로고침 없이 곧바로 **이전 멤버** 목록에 나타납니다. (추방과 동일하게 동작)
- 멤버가 목록에서 잠깐 사라졌다가 다시 나타나는 **깜빡임**을 줄이기 위해, 나가기·추방 이벤트 시 목록에서 삭제하지 않고 **나간 상태**로만 갱신합니다.
- 예전에 나갔던 사람이 **다시 입장을 요청**한 뒤 승인되면, 승인 시점에 다시 **현재 멤버** 목록으로 돌아옵니다. (요청 대기 중에는 멤버 설정 화면의 어느 섹션에도 노출하지 않음)

## 채팅·기타 화면

- 채팅의 온라인 인원 수, 과거 메시지 발신자 이름 표시 등은 기존과 같이 동작합니다.
- 나간 멤버 정보는 채팅에서 과거 메시지의 닉네임·프로필을 보여 주는 데 계속 활용됩니다.
